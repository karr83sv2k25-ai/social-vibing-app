# 🎯 Quick Start: Peer-to-Peer Marketplace

## For New Sellers (2 Minutes)

### Step 1: Become a Seller
```
1. Open app
2. Tap "Marketplace" tab at bottom
3. Tap the purple/pink gradient button: "🚀 Start Selling"
4. Fill in:
   ├─ Store Name: "My Anime Store"
   └─ Store Description: "Quality anime art" (optional)
5. ✅ Check "I agree to Seller Terms"
6. Tap "Start Selling Now"
7. 🎉 You're now a seller!
```

### Step 2: Create Your First Product
```
1. Tap "📦 My Store" button (same place as "Start Selling")
2. In Seller Dashboard, tap "Create New Product"
3. Step 1: Choose Type
   ├─ Select: 📚 Comics, 🎨 Art, 😊 Stickers, etc.
   └─ Enter product title
4. Step 2: Add Content
   ├─ Upload cover image (tap camera icon)
   ├─ Add preview images
   ├─ Upload asset files (PDF, ZIP, etc.)
   └─ Write description
5. Step 3: Set Price
   ├─ Choose currency: 💰 Coins or 💎 Diamonds
   ├─ Enter price (e.g., 50)
   └─ Review and tap "Publish"
6. ✅ Product is now live in Marketplace!
```

### Step 3: Track Your Earnings
```
Your Seller Dashboard shows:
├─ 📦 Products: Total products created
├─ 🛒 Sales: Number of purchases
├─ 💰 Earnings: Total coins/diamonds earned
└─ ✅ Active: Currently available products

Earnings Card:
├─ Available Balance: Ready to withdraw
├─ Commission: You earn 70% per sale
└─ Withdraw button (min 100 coins)
```

## For Buyers (1 Minute)

### How to Buy
```
1. Open "Marketplace" tab
2. Browse products:
   ├─ Popular: Best-selling items
   ├─ Freebies: Free downloads
   ├─ Officials: Admin-curated products
   └─ Community's: User-created products
3. Tap any product
4. View details, screenshots, creator info
5. Tap "Buy Now" button
6. Confirm purchase
7. ✅ Product added to Library instantly!
```

### Categories Quick Access
```
Tap category icons at top:
├─ 📚 Comics: Manga, graphic novels
├─ 📖 Books: E-books, guides
├─ 🎨 Art: Wallpapers, illustrations
├─ 😊 Stickers: Chat sticker packs
├─ 🖼️ Frames: Profile frames
└─ 💬 Bubbles: Chat bubble styles
```

## 💡 Pro Tips

### For Sellers
- ✨ Use high-quality cover images (1000x1000px minimum)
- 📝 Write detailed descriptions
- 💰 Price competitively (check similar products)
- 🎯 Use clear, searchable titles
- 🚀 Create multiple products to increase visibility
- 📊 Check dashboard regularly for insights

### For Maximizing Sales
- Create product bundles
- Offer first product at lower price
- Add preview images (3-5 images)
- Update products based on feedback
- Stay active and create regularly
